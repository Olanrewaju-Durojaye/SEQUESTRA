# Third-party scientific software

SEQUESTRA orchestrates independently installed scientific tools but does not
redistribute their source code, model weights or datasets.

- BoltzGen
- DLKcat
- CatPred
- Boltz-2

Users are responsible for installing compatible versions and complying with
each upstream project's license, model terms, dataset terms and citation
requirements. The SEQUESTRA MIT license applies only to SEQUESTRA's own source
code. ENZTRA and BOLTRA are not runtime dependencies.
